# Validation record

## Environment and scope

The v0.2 acceptance runs used Windows, Autodesk Fusion **2705.1.11**, Python **3.12**, and MCP Python SDK **1.30.0**, on September 10, 2026. The native endpoint used loopback HTTP. These results cover generated fixtures on that installation, not all versions or arbitrary customer designs.

## Recorded results

| Workflow | Evidence checked | Result |
| --- | --- | --- |
| Offline contracts | 26 tests: schemas, durable replay, uncertain-write blocking, document guard, session/error handling, source transport and completion marker | Passed |
| Mechanical features | Constrained rectangles/circles; extrude, revolve, loft, sweep, fillet, chamfer, shell, combine, patterns and holes | Passed |
| Design checks/export | Parameters, geometry queries, numerical checks, feature health, BOM, interference, STEP and sketch DXF | Passed |
| Rigid assembly | Two solid components and an as-built rigid joint, independently inspected | Passed in v0.1 |
| CAM face workflow | Explicit library/tool selection, setup, face operation, async generation, valid toolpath polling | Passed |
| Existing nested assembly | Two Module instances sharing a Pin; edit 20 to 25 mm, inspect both, verify unrelated component unchanged | Passed through an actual stdio MCP client |
| Edit rejection | Shared edit without acknowledgement, stale fingerprint, foreign model parameter | Rejected as expected |
| Archive round-trip | Export fixture to F3D, close only that fixture, reopen, rediscover, edit 25 to 30 mm | Passed |

The early feature run affected by silent native nonexecution is excluded from successful evidence. The bridge now splits long source literals and requires an execution-completion marker; successful fixtures were rerun after that fix.

## Validation gaps

NC program creation, post-processing, cloud drawing creation, STL export, and revolute/slider joints are implemented but have not been live-validated. Machine code was not generated by these acceptance runs. CAM simulation, arbitrary topology repair, automatic linked-source editing, and making one instance independent are not implemented.

macOS and other Fusion versions have not been validated. The original v0.1 example plate leaves hole positions underconstrained; do not treat it as evidence for the newer fully constrained typed-sketch workflow.

Raw reports and model files are local development artifacts excluded from the public repository. Reproduce the runs with [testing.md](testing.md). Changes to the validated behavior should update this record with environment, checks, outcomes, and limitations.
